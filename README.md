# منظومة باركود الأصول — راكان لاستيراد المواد الغذائية والتوزيع

منظومة ويب لتسجيل الأصول الثابتة وطباعة ملصقات الباركود على طابعات XPrinter، مع الربط بأصول أودو.

**الرابط:** https://olympy-nd.github.io/rakan-asset-barcode/

## مصدر البيانات
- **Google Sheets (سحابي):** قاعدة مشتركة من أي جهاز، تُحفظ التغييرات تلقائياً.
- **ملف Excel على الجهاز:** ملف .xlsx محلي (Chrome / Edge).

> هذا المستودع عام ولا يحتوي أي بيانات. البيانات كلها في Google Sheet خاص بالشركة.

## إعداد Google Sheets (مرة واحدة)
1. افتح المنظومة ← **الإعدادات ← مصدر البيانات ← Google Sheets**.
2. اضغط **نسخ كود Apps Script** (أو انسخ `apps-script/Code.gs` من هذا المستودع).
3. افتح ملف Google Sheet ← **الإضافات ← Apps Script** ← الصق الكود ← حفظ.
4. **نشر ← نشر جديد ← تطبيق ويب** · التنفيذ باسم: أنا · الوصول: أي شخص ← نشر.
5. الصق **رابط تطبيق الويب** في المنظومة ← **حفظ الرابط والاتصال**، ثم أدخل **رمز الدخول**. أول رمز يُدخَل يصبح رمز المنظومة.

على كل جهاز آخر: افتح الرابط وأدخل رمز الدخول مرة واحدة، وبعدها تتصل المنظومة تلقائياً.

⚠️ لا تكتب رمز الدخول في هذا المستودع. لتغيير الرمز شغّل الدالة `resetKey` من محرر Apps Script ثم أدخل الرمز الجديد.

## أوراق الشيت
| الورقة | المحتوى |
|---|---|
| الأصول | الأصول المسجلة وباركود كل أصل وربطه بأودو |
| أصول أودو | آخر ملف أصول مستورد من أودو |
| الفئات | فئات الأصول ورموزها |
| سجل الطباعة | كل عملية طباعة |
| الإعدادات | اسم الشركة ونظام الترقيم وطريقة ربط أودو |

## الطابعة
XPrinter XP-P322B / XP-365B — أنشئ ورقاً بمقاس الملصق في تعريف الطابعة (المقاس الافتراضي 40×70 مم) واطبع بهوامش «بلا» ومقياس 100%.
